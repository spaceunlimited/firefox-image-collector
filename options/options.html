Image Collector settings

Site access

With access to all websites, the extension downloads the original image file itself. Without it, images from sites that block other origins are saved but can't be copied.

Automatic cleanup

Export

JSON is a full backup including thumbnails and tags. CSV has one row per capture, for spreadsheets.

Import

Imports a JSON export. Images already in the collection are merged, not duplicated.

Storage

Delete everything

Removes all collected images. Settings are kept.
